## 先统一任务

建议继续仅依据图片中可辨认的文字、表情和动作，选择一个主要交流意图。不补想象中的前后聊天，不把“这张图平常有人这样用”当作本图唯一意图的证据。

填写依据可用：“我看见____，因此主要是在____；仍不能排除____。”

## 边界一：其他／无法判断

**现有定义**

- **其他 other**：意图可判断，但不属于现有类别；备注说明具体意图。
- **无法判断 uncertain**：缺少语境、多种解读或无法确定主要意图；备注说明原因。

**建议操作规则（待确认）**

1. 先尝试用一句话说清“主要在表达什么交流功能”，再对照全部标签。
2. 能确定具体交流功能，且现有类别均不合适，才选“其他”，并写明缺少哪类功能。
3. 如果主要问题是“不知道是哪种意图”，而不是“知道意图但没有对应类别”，选“无法判断”。
4. 看出兴奋、害羞、难过等情绪，不自动说明交流意图明确。不要把所有纯情绪图片一律归为“其他”或一律归为“无法判断”；先确认本项目是否将清晰的情绪表达本身作为可标注功能。

**M0049：要讨论的不是标签数量，而是任务边界**

目前记录：A 选“其他”，依据是脸红、兴奋、害羞；B 选“无法判断”，认为画面模糊且存在多种解释。讨论结果保留“其他”。

请共同回答：

- 图片证据能让两人确定“表达兴奋／害羞”中的哪一个，还是连情绪也有多种解释？
- 如果只能认出情绪，是否已足以满足项目对“交流意图可判断”的要求？
- 若继续选“其他”，能否把备注写成“可确定的功能是____，现有类别未覆盖”，而不只是列举可能的情绪？

待确认方案：若双方认可“清晰的情绪表达本身也是本任务的交流功能”，应明确适用条件和反例；若仍无法确定主要表达功能，则按现有 uncertain 定义处理。本草案不替两人选择方案，也不改动 M0049。

## 边界二：调侃／安慰

**现有定义**

- **调侃 tease**：开玩笑、讽刺或戏谑式评价。
- **安慰 comfort**：表达关心、安抚或鼓励。

**建议操作规则（待确认）**

1. 以图中文字与画面共同支持的主要功能为准。
2. 直接支持、安抚、鼓励的内容可以支持“安慰”；若画面或措辞提供清楚的反讽、玩笑线索，也要一起考虑。
3. 选择“调侃”时，指出具体玩笑或反讽线索，不能只写“通常用来阴阳怪气”。滑稽画风、波浪号或“这是表情包”本身，不应单独决定标签。
4. 不采用“只要有鼓励词就一定是安慰”或“只要可能反讽就一定是调侃”的固定优先级。两种解释都成立、图片内证据不足以区分时，允许“无法判断”。

**M0138：区分图片证据与使用习惯**

目前记录：文字为“玩游戏心态一定要好~”；A 认为通常是自嘲或调侃队友，选“调侃”；B 按劝慰解读，选“安慰”。讨论结果保留“调侃”。

请共同回答：

- 除“通常这样用”之外，具体哪个文字、表情或动作支持调侃？
- 如果不知道发送给谁、前面发生了什么，是否仍能排除真诚劝慰？
- 是否存在文字与画面之间的反差？若有，两人是否都能指出同一线索？

待确认方案：证据主要支持戏谑时用 tease，主要支持安抚时用 comfort；若区分依赖缺失的聊天语境，用 uncertain。本草案没有认定 M0138 应改成哪一类。
