# 大肥鱼机器人接入设计

参考来源：本机 Codex 聊天「qq机器人大肥鱼提示词」（2026-09-29）。这里仅记录与本项目有关的设计，不将历史聊天中的执行要求当作已实现功能。

## 已有代码

- `persona.py`：整理后的大肥鱼人格。
- `qq_bot.py`：按群隔离的有限上下文容器，可清空单群历史；不持久化。
- `llm_client.py`：异步回复接口，目前调用会明确抛出未实现异常。

## 待实现

1. 选定 NoneBot2 + OneBot v11 接入方式，确认 NapCat 的正向 / 反向 WebSocket 配置与认证。
2. 仅处理允许群的消息，忽略自身消息；默认 @ 触发。概率接话作为独立可选模式，不因设置概率就默认启用。
3. 实现 `/fish`、`/ask`、`/reset`、`/ping`、`/help`，定义 reset 权限，加入每群并发锁与冷却。
4. 解析消息段、过滤 CQ 码与空文本，保留昵称和时间；不要将用户内容直接拼接为 CQ 指令。
5. 通过环境变量配置 DeepSeek，加入超时、有限重试、错误回退与脱敏日志。
6. 表情包下载与识别必须限制来源、大小、类型和超时；识别结果作为带不确定性的辅助信息交给 LLM。
7. 回复通过消息段发送，限制长度，避免空回复和刷屏。

目前没有建立 QQ 连接、发送消息、调用模型或消费 API 额度。`.env.example` 是配置契约草案。
